Prompt 2:
	Now can you make a function to take the 32-bit unsigned long and turn it back into it's Octet form, with 4 split 8 bit integers, like the original IP form (A.B.C.D) as a string
	
Response 2:
	I added ipv4ToString to the same file:

	std::string ipv4ToString(unsigned long address)
	{
		std::string result;
		for (int shift = 24; shift >= 0; shift -= 8) {
			unsigned int octet = static_cast<unsigned int>((address >> shift) & 0xFFUL);
			result += std::to_string(octet);
			if (shift > 0)
				result += '.';
		}
		return result;
	}

	It takes the four 8-bit groups from the top down: shift right by 24, then 16, then 8, then 0, and keep the low 8 bits (& 0xFF) each time. That's the reverse of how extractIPv4 built the number, so 0xC0A80101 becomes "192.168.1.1". The new tests pass, including a round trip through both functions ("...172.16.254.3:443..." → number → "172.16.254.3").

	I used std::to_string here because your rules only banned string-to-number conversion, not number-to-string. If you'd rather avoid it too, I can swap in a short hand-written digit loop.
